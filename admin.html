Ikuti langkah di bawah ini untuk menyimpan konten secara permanen:

  1. Klik tombol hijau " Salin Hasil Kode" di bawah ini.
  2. Pergi ke halaman GitHub Anda, lalu buka file index.html.
  3. Hapus total isinya yang lama, lalu tempel (paste) kode baru ini ke sana.
  4. Klik Commit Changes di GitHub. Website Anda otomatis terisi sempurna!
